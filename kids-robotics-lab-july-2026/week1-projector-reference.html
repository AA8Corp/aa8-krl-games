Week 1 — Robot Memory: Variables & Talking to Your Program

Mini-lesson snippets (predict → run)

1 · The box

robot_name = "Rusty"
battery = 100

2 · Reading the box (f-string)

print(f"My robot is {robot_name}, battery {battery}%")

3 · Changing the box

battery = battery - 10
print(f"After driving: {battery}%")

4 · input() = the program's ears

pilot = input("Who is driving? ")
print(f"Welcome aboard, {pilot}!")

Common bugs — read the error together, don't panic

  • Missing quote or parenthesis → read the line number in the red error.
  • Print vs print — Python is case-sensitive.
  • Forgot the f → it prints {robot_name} literally (show this once!).
  • Doing math on input()? Wrap it: int(input(...)).
