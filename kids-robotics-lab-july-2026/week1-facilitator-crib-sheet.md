# Week 1 Crib Sheet — Robot Memory (at-a-glance for the Lead Instructor)

**Session 1 of 3 · 6:00–8:00 PM · keep this beside the laptop.**

## The one-line story
"In three weeks you'll teach a robot to think. **Tonight we give it a memory.**"

## Timing (glance-and-go)

| Time | Segment | Your job in one line |
|------|---------|----------------------|
| 6:00 | Meal & settle-in | Circulate, ask what they recall from Hello World |
| 6:10 | Welcome + warm-up | Type `print("Hello, Robotics Lab!")`, edit it live to greet 3 kids |
| 6:20 | Mini-lesson (4 beats) | Box → f-string → change it → `input()`. **Predict before every Run.** Break things on purpose. |
| 6:40 | Guided: Robot ID Badge | Target: output on screen in <10 min. Push kids L1→L2→L3. |
| 7:05 | Brain break: Robot Freeze | "Charge Battery = which variable?" (battery) |
| 7:10 | Main: Robot Mad Libs (pairs) | Navigator + driver, swap halfway. Reveal `.upper()` at the midpoint. |
| 7:40 | Showcase | 3–4 pairs run it, you answer the prompts. "Which line was hardest?" |
| 7:52 | Wrap-up | Exit ticket + **save Replit projects** + tease Week 2 (decisions). |

## Say these out loud
- "You've done this with blocks a hundred times — Python just spells it with an equals sign."
- "Predict what this prints *before* I run it."
- "An error isn't failure — it's a clue. Let's read the line number."
- Tease: "Your robot has memory. Next week it gets a **brain** — it makes its own decisions."

## Deliberate 'mistakes' to demo on the projector
1. Drop a quote → show the error, read the line number together.
2. Type `Print` → case-sensitivity.
3. Forget the `f` in an f-string → it prints `{robot_name}` literally.
4. The `.upper()` "cheat code" reveal mid-Mad-Libs — reliable laugh.
